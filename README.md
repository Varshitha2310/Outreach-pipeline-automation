# Outreach Pipeline Automation

A Python tool that replaces manual tracking of sponsor/partner outreach. It reads a tracker
spreadsheet (CSV) and automatically flags overdue follow-ups, drafts follow-up messages, calculates
funnel conversion and pipeline value, and writes a weekly report.

Inspired by managing sponsorship outreach for a college fest, where follow-ups were tracked manually.

> **Data note:** The sample tracker is fictional, generated by `generate_sample_data.py`.
> Replace `data/outreach_tracker.csv` with your own data using the same columns.

## What it automates
- Overdue / due-soon follow-up detection
- Stage-specific draft follow-up messages
- Funnel counts, win rate, open pipeline value
- Performance by owner and win rate by sector
- Weekly Markdown report

## Run
```bash
pip install -r requirements.txt
python generate_sample_data.py     # skip if you use your own CSV
python tracker.py
```
Outputs: `reports/weekly_report.md`, `reports/followups_due.csv`

## CSV columns
`company, sector, stage, owner, last_contact_date, next_followup_date, expected_value_inr`
